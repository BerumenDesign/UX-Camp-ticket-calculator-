# UX Camp Ticket Calculator

A single-page budget and ticket-pricing calculator for UX Camp Calgary.

Open `index.html` in Chrome or Safari — no install or server needed.

- **2025** and **2026** tabs hold read-only actuals.
- **+ New** or **Duplicate** creates a scenario you can edit.
- Changes save automatically in your browser. Use **Save scenarios to file** / **Load from file** to move them between browsers or computers.
- **Export CSV** downloads the current scenario.
